消息與活動 後台管理示意

這不是具登入保護的正式後台。 所有輸入僅保存在本機瀏覽器記憶體；可保留 JSON 草稿，或使用 GitHub 授權直接發布至公開網站。發布需持有儲存庫寫入權限，並非無驗證後台；請勿使用機關正式帳密或輸入未核定與敏感資訊。請勿輸入未經核定或敏感資訊。

圖片與圖說 Images & Captions

可選擇 JPEG、PNG、WebP 圖片，最多 4 張，每張可分別設定「圖片說明」與「替代文字」。新增時會自動壓縮圖片，以利示意預覽與發布；第一張圖片會作為消息列表封面。

圖片原始大小上限 8 MB／張；壓縮後存於本機示意文章，切換其他瀏覽器不會同步。圖片需有清楚的替代文字以利無障礙閱讀。

直接發布設定（GitHub）

進行跨裝置 GitHub 同步時，使用 GitHub fine-grained Personal Access Token，僅授權 cdcamr/taiwan-amr-atlas 儲存庫的 Contents: Read and write。權杖只在目前頁面記憶體中使用，不會儲存於瀏覽器或儲存庫；關閉頁面即需重新輸入。此方式僅供原型，正式 CMS 應改用機關登入與伺服器端授權。

圖片使用獨立檔案上傳至 assets/news/images/，文章資訊則更新 main 分支的 data/news/manifest.json。同文章代碼將覆蓋原文章，請先確認資料及備份。GitHub Pages 部署完成後才會在網站顯示。

本機示意文章管理

可從此瀏覽器繼續編輯、下架、重新發布或刪除文章。資料儲存於瀏覽器本機，不會跨裝置同步。

GitHub 同步發布程序

① 填寫文章、上傳圖片與圖說並預覽 → ② 確認內容已獲核定 → ③ 填入具有儲存庫寫入權限的 GitHub 權杖 → ④ 點選「GitHub 同步發布（需授權）」並確認 → ⑤ 系統更新公開文章清單，待 GitHub Pages 部署後顯示。仍可匯出草稿交由其他人審核。

注意：公開清單中尚未有正式審核文章時，前台呈現空白狀態；正式 CMS 角色權限、排程、附件上傳及完整稽核仍待建置。
