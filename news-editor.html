直接發布設定（GitHub）

進行跨裝置 GitHub 同步時，使用 GitHub fine-grained Personal Access Token，僅授權 cdcamr/taiwan-amr-atlas 儲存庫的 Contents: Read and write。權杖只在目前頁面記憶體中使用，不會儲存於瀏覽器或儲存庫；關閉頁面即需重新輸入。此方式僅供原型，正式 CMS 應改用機關登入與伺服器端授權。

發布會直接更新 main 分支的 data/news/manifest.json。同文章代碼將覆蓋原文章，請先確認資料及備份。GitHub Pages 部署完成後才會在網站顯示。

GitHub 同步發布程序

① 填寫並預覽 → ② 確認內容已獲核定 → ③ 填入具有儲存庫寫入權限的 GitHub 權杖 → ④ 點選「GitHub 同步發布（需授權）」並確認 → ⑤ 系統更新公開文章清單，待 GitHub Pages 部署後顯示。仍可匯出草稿交由其他人審核。

注意：公開清單中尚未有正式審核文章時，前台呈現空白狀態；正式 CMS 角色權限、排程、附件上傳及完整稽核仍待建置。
