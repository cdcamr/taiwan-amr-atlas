最新消息與活動 內容發布管理

跨裝置發布說明：「發布到共用網站」及「一次同步既有已發布消息」會把內容與圖片寫入 GitHub Pages，手機和其他裝置都能透過網址查看。GitHub Pages 是公開網站，並非僅限收到網址的人；請勿發布個資、機關內部或未核定資料。正式帳密與角色權限將於下一階段建置。目前仍須使用具儲存庫寫入權限的 GitHub 授權。

圖片與圖說 Images & Captions

可選擇 JPEG、PNG、WebP 圖片，最多 4 張，每張可分別設定「圖片說明」與「替代文字」。新增時會自動壓縮圖片，以利示意預覽與發布；第一張圖片會作為消息列表封面。

圖片原始大小上限 8 MB／張；壓縮後存於本機示意文章，切換其他瀏覽器不會同步。圖片需有清楚的替代文字以利無障礙閱讀。若前台顯示圖片無法載入，請在此重新選擇圖片並一鍵發布；本機示意資料不會跨瀏覽器同步。

文章多語版本 English & Japanese

上方「文章標題／摘要／內文」為繁體中文原始版本。請在以下欄位填入英文、日文譯文，前台會依語言選擇顯示。翻譯未填寫時會顯示原文並提醒；此靜態網站不會自動呼叫外部翻譯服務，請於正式發布前確認譯文正確。

跨裝置發布設定（GitHub）

進行跨裝置 GitHub 同步時，使用 GitHub fine-grained Personal Access Token，僅授權 cdcamr/taiwan-amr-atlas 儲存庫的 Contents: Read and write。權杖只在目前頁面記憶體中使用，不會儲存於瀏覽器或儲存庫；關閉頁面即需重新輸入。此方式僅供原型，正式 CMS 應改用機關登入與伺服器端授權。

開啟 Token 設定 ↗

此檢查只驗證帳號與儲存庫權限資訊，不會建立或修改 GitHub 檔案。若圖片上傳發生 403，請先查看此處診斷。

此儲存庫由 cdcamr 個人帳號持有。建立 Fine-grained Token 時，請選擇 Resource owner：cdcamr、僅授權 taiwan-amr-atlas，以及 Repository permissions → Contents: Read and write。請勿將 Token 貼到聊天或螢幕截圖。

圖片會同步至 assets/news/images/，文章寫入 data/news/manifest.json。提交成功後，待 GitHub Pages 部署完成即可由手機查看；新的單篇發布若文章代碼相同，會更新既有內容。

跨裝置發布流程

① 在原本發布消息的瀏覽器開啟後臺 → ② 填入 GitHub 寫入授權 → ③ 點選「一次同步既有已發布消息」 → ④ 文章、圖片及圖說寫入網站公開清單 → ⑤ 等待 GitHub Pages 部署後，在手機開啟 NEWS & EVENTS 檢查。日後新增消息，可直接使用「發布到共用網站」。

若本機已清除網站資料，原本保存在瀏覽器的示意文章無法從 GitHub 自動找回；可以使用先前匯出的 JSON 草稿匯入。正式 CMS 的帳號密碼及權限控管仍待建置。
