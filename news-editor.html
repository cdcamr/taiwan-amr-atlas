審核發布程序

① 匯出草稿 JSON → ② 經業務核定及內容審查 → ③ 由維護人員修改 data/news/manifest.json，將通過審核的文章納入 articles 清單並設定 status: published → ④ 提交 Pull Request → ⑤ 審核合併及部署後顯示於前台。

注意：公開清單中尚未有正式審核文章時，前台呈現空白狀態；正式 CMS 帳號權限、排程、上傳、稽核仍待建置。
